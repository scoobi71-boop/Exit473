How to Update the Website

This guide explains how to add, edit, or remove business listings by editing a simple spreadsheet file. No coding required.

Overview

The Data File

All business listings on the website are stored in a single file:

data/businesses.csv

This is a standard CSV (Comma Separated Values) file. You can open and edit it with:

  • Microsoft Excel — open the file directly
  • Google Sheets — File → Import → upload the CSV
  • LibreOffice Calc — free and open source
  • Any plain text editor (Notepad, TextEdit, VS Code)
💡 Tip: Google Sheets is the easiest option for non-technical editors. Open the file in Sheets, make your changes, then download it as CSV (File → Download → CSV) and replace the old file.
Step by Step

Updating a Business Listing

1

Locate the file

Find data/businesses.csv in your website folder.

2

Open in a spreadsheet app

Double-click to open in Excel, or drag it into Google Sheets. Each row is one business; each column is one piece of information.

3

Make your changes

Edit any cell. Update a phone number, change hours, add a website link, or add a whole new row for a new business.

4

Save as CSV

In Excel: File → Save As → choose "CSV (Comma delimited) .csv". In Google Sheets: File → Download → Comma Separated Values (.csv).

5

Upload to your server

Replace the old data/businesses.csv on your web hosting with the new file. The website updates automatically — no other changes needed.

Adding New Listings

How to Add a New Business

To add a new business, simply add a new row at the bottom of the CSV file. Give it a unique id number (the next number in sequence) and fill in all the columns.

🚀 To make it featured (shown on the homepage), set featured to true. We recommend featuring no more than 5–6 businesses so the homepage stays clean.

Here's an example row you can copy as a template:

Removing Listings

How to Remove a Business

To remove a business, simply delete the entire row for that business in the CSV file. Do not leave blank rows — delete the row completely.

⚠️ Do not renumber the IDs of remaining businesses after a deletion. Gaps in ID numbers are fine and won't cause any problems.
Advanced

Updating Park-Wide Information

To update the park name, address, phone, email, or social media links that appear site-wide, open js/app.js in a text editor and edit the SITE_CONFIG block at the top of the file:

const SITE_CONFIG = { complexName: 'Exit 473', tagline: "Grenada's Premier Business Destination", location: "St. George's, Grenada, West Indies", phone: '+1 (473) 403-7377', email: 'exit473.gd@gmail.com', address: 'Maurice Bishop Highway, Grand Anse, St George\'s, Grenada, W.I.', hours: 'Mon–Sun 7am – Midnight', mapLink: 'https://maps.google.com/?q=Exit+473+Grenada', ... };

Save the file and upload it to replace the old version. Contact info in the footer and contact page will update automatically.

Technical Note

Important: Web Server Required

This website loads business data dynamically from the CSV file. For this to work, the site must be served from a web server — it cannot be opened by double-clicking the HTML files directly on your computer.

This is not a problem once the site is hosted online. Recommended hosting options:

  • cPanel hosting (most traditional web hosts) — upload via File Manager
  • Netlify — drag and drop your folder to netlify.com for free hosting
  • GitHub Pages — free hosting via GitHub
💡 Local testing: If you want to preview the site on your own computer before uploading, you can run a simple local server using Python: open Terminal/Command Prompt in the website folder and type: python -m http.server 8000 then visit http://localhost:8000 in your browser.
